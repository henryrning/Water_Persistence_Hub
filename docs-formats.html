Data formats

What you get in each download and how to read it. This page and the README inside every ZIP are generated from the same source.

What’s in the ZIP

Every download is one ZIP archive, covering the counties, years and planting window you chose. It always contains:

FileFormatPurpose
README.txtTextThis page, plus your selection restated, so the package describes itself.
manifest.csvCSVEvery file in the package with its size and SHA-256 checksum.
TERMS.txtTextThe Terms of Use version that applied when the package was made.
WPH_…​.tifGeoTIFFOne raster per county and year you selected.

Pixel values

Each pixel stores a single percentage — not a yes/no mask. There is one file per county and year; the three familiar cutoffs (70/80/90%) are something you apply yourself, either in your own GIS or as a view on the download map (see Download).

ValueMeaning
0–100Share of usable days under water. E.g. a pixel valued 82 was labelled water on 82% of the clear-sky days it could be observed in the planting window.
255No data — outside the county, or no valid observation for the whole window.

Planting window

Three window options. Default uses the same dates everywhere; Corn and Soybean use typical local planting dates, which are different for every county. Example state-level dates — the README for your download lists the exact dates for each county you selected:

Reading the percentage

Apply your own threshold in GIS — for example, a raster calculator expression like value >= 80 reproduces the old “80% cutoff” mask. As a worked example, in Ramsey County, ND, 2025:

ThresholdRuleWater areaShare of valid pixels
≥ 70%Water on 70% or more of usable days510.7 km²15.2%
≥ 80%Water on 80% or more of usable days501.4 km²14.9%
≥ 90%Water on 90% or more of usable days489.0 km²14.5%

Because it is one continuous file, you can threshold at any percentage you choose — 70/80/90% are common starting points, not the only options.

How the layer was produced

Daily satellite images across the planting window are screened for standing water. Each 3 m pixel is labelled water or dry on every clear day. The share of clear days labelled water becomes the pixel’s 0–100% value. See Cautions & accuracy for validation results.

Scripted access Coming soon

This endpoint is not live yet. The request shape below is the planned design, shown so AIPs with recurring seasonal pulls can plan for it.

For repeat seasonal pulls, request the same packages the download page builds. A personal token will be issued from My downloads once this is live.

# 1. Request a package
curl -X POST -H "Authorization: Token $WPH_TOKEN" \
  "https://waterhub.illinois.edu/api/v1/packages?counties=38071&years=2025&window=corn"

# 2. Poll until "status": "ready", then download "download_url"
curl -H "Authorization: Token $WPH_TOKEN" https://waterhub.illinois.edu/api/v1/packages/<id>
ParameterValues
countiesComma-separated FIPS codes, or state=ND for every covered county
yearsOne or more published years, comma-separated, e.g. 2025
windowdefault, corn or soybean
